# TypeScript Practice & Blog Writing Assignment

## About This Assignment

This assignment is designed to improve my TypeScript fundamentals through practical coding problems and technical blog writing.

The main goal is to understand TypeScript concepts, practice writing clean code, and improve my problem-solving skills.

## Part 1: TypeScript Problem Solving

In this section, I practiced TypeScript problems related to functions, interfaces, generics, and array methods.

### Problems Covered

1. **Generic Array Concatenation**
   - Created a generic function using rest parameters.
   - Combined multiple arrays into a single array.
   - Practiced TypeScript Generics.

2. **Course Filtering**
   - Created a `Course` interface.
   - Used the `filter()` method to find popular published courses.
   - Practiced working with interfaces and arrays.

3. **Generic Property Extraction**
   - Created a generic `pluckValues` function.
   - Used `keyof` constraints and indexed access types.
   - Extracted specific property values from objects.

## Part 2: Technical Blog Writing

In this section, I wrote technical blogs to improve my understanding of TypeScript concepts.

### Blog Topics

1. **Type vs Interface in TypeScript**
   - Differences between type aliases and interfaces.
   - When to use each one.

2. **Understanding any, unknown, and never**
   - Understanding TypeScript's special types.
   - Why `unknown` is safer than `any`.

3. **Combining Union and Intersection Types**
   - Understanding Union (`|`) types.
   - Understanding Intersection (`&`) types.
   - Combining both with practical examples.
